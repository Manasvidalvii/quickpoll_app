# 🗳️ QuickPoll Pro - Real-Time Polling Application

**QuickPoll Pro** is a full-stack, real-time polling application designed to let users create, vote on, and analyze custom polls instantly. Built with clean UI/UX and lightweight architecture, it allows seamless poll distribution via shareable links and dynamic scannable QR codes.

🚀 **Live Demo:** [https://quickpoll-app-ten.vercel.app](https://quickpoll-app-ten.vercel.app)

## ✨ Key Features

* 📊 **Real-Time Poll Analytics:** Visual progress bars with dynamic percentage calculations and a toggleable chart view.
* 📱 **Instant QR Code Sharing:** Automatically generates scannable QR codes for easy mobile voting access.
* ⏳ **Custom Timers & Expiration:** Set custom expiration windows for active voting sessions.
* 🔗 **One-Click Link Sharing:** Copies dynamic direct URLs straight to your clipboard.
* 🎨 **Modern & Responsive UI:** Clean card layout with built-in dark/light mode toggle options.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Chart.js, QRCode.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB / MongoDB Atlas
* **Deployment:** Vercel (Frontend), Render (Backend)
